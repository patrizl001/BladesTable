# Notice for the files in this folder

`talents.json`, `rules_sections.json`, `bestiary.json`, `examples.json` and `gm_guide.md` are derived
from the rulebook of **Blades of Ether** by Alexis Eva, Kaylee Maya and Ruby Soleil-Raine
(https://gears.link/blades), which is licensed under
[Creative Commons Attribution-NonCommercial-ShareAlike 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

* `talents.json`, `rules_sections.json`, `bestiary.json` and `examples.json` are extractions of the book's
  text (reflowed and split into records; a few tables retyped by hand).
* `gm_guide.md` is an original condensed guide that paraphrases and summarises the book's rules and
  Architect advice, so it is treated as a derivative of the book too.

These files are therefore shared under the same licence (CC BY-NC-SA 4.0): attribute the original authors,
do not use them commercially, and share adaptations under the same terms. Changes were made.

This is an unofficial fan project; it is not affiliated with or endorsed by the authors.
The rulebook itself is not included in this repository; get it from the authors.

If you adapt this project to another game, replace this folder's contents with data for that game and
update or remove this notice accordingly.
